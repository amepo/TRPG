# 灯火のテーブル

ブラウザだけで遊べる **d20 系 TRPG**。ビルド不要・実行時の依存パッケージゼロ・**完全オフライン**。
データはすべて端末内（localStorage）で処理され、サーバーには何も送信されません。

**2つの世界観**を収録しています。シナリオを選ぶと世界が切り替わり、クラス・装備・敵・技能・配色、
そして固有ルールまで丸ごと入れ替わります。

| 世界観 | 内容 |
| --- | --- |
| 🕯️ **灯火のテーブル** | 剣と魔法のファンタジー。種族6／クラス5／技能18／呪文16／モンスター16 |
| 🌃 **ネオンの雨** | 企業に支配された街。出自6／役割5／技能18／プログラム16／敵15。**サイバーウェア**と**ネットラン**が加わる |

```bash
npm start          # → http://localhost:5173/
```

> ES Modules を使っているため、`index.html` をダブルクリックして `file://` で開くと動きません。
> 上記のローカルサーバー（依存なしの Node 製、`tools/serve.js`）経由で開いてください。

スマホでは **ホーム画面に追加**すると全画面で起動し、オフラインでも全機能が使えます。

## 3つのモード

| モード | できること |
| --- | --- |
| **ソロプレイ** | シナリオを選び、一人で最初から最後まで遊ぶ。判定も戦闘も自動処理。 |
| **セッション支援** | 対面／オンラインの卓で使う道具。ダイス、キャラクターシート、イニシアチブ表。世界観は画面上部で切り替えます。 |
| **シナリオ工房** | 自分の物語を書く。判定・戦闘・分岐・複数エンディング。書いたものはそのまま遊べる。 |

## サイバーパンク固有のルール

**サイバーウェア（適合度）** — 改造は強いが、体が受け入れる量には上限があります（`3 ＋ 耐性修正 ＋ レベル/2`）。
超過したぶんだけ、**すべての判定・セーヴ・攻撃に固定のペナルティ**がつきます。
「もう一つ入れるか、抑えるか」を毎回選ばせるための仕組みです。

**ネットラン（電脳侵入）** — 防壁を層ごとに抜けていくミニゲーム。毎層、抜け方を選びます。

| 手 | 判定 | 痕跡 |
| --- | --- | --- |
| 慎重に潜る | 有利 | 成否にかかわらず +1 |
| 一気に押し通る | 通常 | 成功 0／失敗 +2 |
| 迂回路を探す | DC +3 | 成功 0／失敗 +2 |
| 強引に焼き切る | 自動成功 | +3、さらに反動ダメージ |

痕跡が上限に達すると逆探知され、ICE との戦闘か、そのまま弾き出されます。

## ルール（d20 系）

- **能力値6種**（筋力・敏捷・耐久・知力・判断・魅力）、修正値は `floor((値−10)/2)`
- **判定**：`1d20 ＋ 能力修正 ＋ 習熟ボーナス` が DC 以上で成功。ナチュラル20は自動成功＋ダメージダイス倍、ナチュラル1は自動失敗
- **有利／不利**：2d20 の高い方／低い方。両方あると打ち消し合う
- **習熟ボーナス**：レベル1〜4で +2、以降4レベルごとに +1（最大10レベル）
- **戦闘**：イニシアチブ順のターン制。攻撃ロール vs AC、状態異常、死亡セーヴ（3回成功で安定／3回失敗で死亡）
- **休憩**：小休憩でヒットダイス消費＋能力回復、長休憩で全快
- 能力値の id は世界共通（`str/dex/con/int/wis/cha`）。呼び名だけが世界ごとに変わります

## ダイス式

`1d20` `2d6+3` `4d6kh3`（高い方3つ）`2d20kl1`（不利）`1d10!`（振り足し）`1d8+1d6-2`

## シナリオの形式

シナリオは素の JSON（プレーンオブジェクト）です。工房で書き出したファイルをそのまま共有できます。

```js
{
  id: 'my-scenario', title: 'タイトル', world: 'embers', start: 'nodeA',
  vars: { trust: 0 },
  nodes: {
    nodeA: {
      title: '場面の見出し', art: '🌫️',
      text: ['本文。{name} で先頭の名前が入る。'],
      onEnter: [{ setFlag: 'met' }, { var: 'trust', add: 1 }],
      choices: [
        { text: '進む', to: 'nodeB' },
        { text: '調べる', check: {
            skill: 'investigation', dc: 12,
            success: { text: ['見つけた。'], to: 'nodeB', effects: [{ giveItem: 'potion' }] },
            fail:    { text: ['何も出てこない。'], to: 'nodeB' },
        } },
        { text: '鍵を使う', requires: { has: 'ironKey' }, lockedText: '鍵がない', to: 'nodeC' },
      ],
    },
    nodeB: {
      title: '戦闘',
      combat: { enemies: ['goblin', 'goblin'], onVictory: { to: 'nodeC' } },
    },
    nodeC: { title: '結末', ending: { type: 'good', title: '生還', text: ['帰り道は静かだった。'] } },
  },
}
```

**条件**：`{flag}` `{noFlag}` `{var,gte|lte|eq}` `{has}` `{classIn}` `{skillIn}` `{alive}` `{levelAtLeast}` `{all|any|not}`
**効果**：`{setFlag}` `{clearFlag}` `{var,add|set}` `{giveItem}` `{takeItem}` `{gold}` `{xp}` `{damage}` `{heal}` `{rest}` `{log}`

`world` はそのシナリオが属する世界観の id（`embers` または `neon`）。省略すると `embers` です。
シナリオを開始すると、その世界が有効になります。**技能の id は世界ごとに違う**ので、
`netops`（電脳）はネオンにしか、`arcana`（魔法学）はファンタジーにしか存在しません。

ネオンの世界では、戦闘のかわりに**侵入**を置けます。

```js
netrun: {
  title: '社内網', traceMax: 6,
  layers: [
    { name: '外周ファイアウォール', skill: 'netops', dc: 12 },
    { name: '認証ゲート', skill: 'tech', dc: 13, onFail: { damage: '1d6' } },
    { name: '保管区画', skill: 'netops', dc: 14, effects: [{ setFlag: 'gotFiles' }] },
  ],
  ice: ['ice'],                       // 逆探知されたときに出てくる相手
  onSuccess: { to: 'node-a' }, onTraced: { to: 'node-b' },
}
```

## 収録シナリオ

**🕯️ 灯火のテーブル（ファンタジー）**
- **はじめての依頼**（10〜15分）— 操作を覚えるための導入編
- **鐘の鳴らない村**（40〜60分）— 29場面／戦闘4／判定23／結末5。村の聞き込みから儀式の阻止まで

**🌃 ネオンの雨（サイバーパンク）**
- **初日の運び屋**（10〜15分）— 導入編。判定・戦闘・ネットラン・改造を一度ずつ通る
- **雨の領収書**（40〜60分）— 探索もの。35場面／戦闘5／侵入1／判定23／結末6。
  消えた弟を追って企業タワーの37階へ。侵入経路は「社員証」「潜入」「ネットラン」の3通り
- **三分間の停電**（30〜45分）— 強盗もの。22場面／判定18／結末5。毎週火曜の停電三分で金庫室へ。
  下見を重ねるほど本番の持ち時間が増える、時間が敵のシナリオ
- **最終便**（30〜45分）— 逃走・護衛もの。22場面／戦闘5／結末6。証人を朝までに街の外へ。
  経路3つ、追跡度と証人との信頼で終わり方が変わる

## 構成

```
index.html                     画面の骨組み
manifest.webmanifest / sw.js   PWA（ホーム画面に追加・オフライン動作）
css/trpg.css                   見た目（ダーク、モバイル優先）
js/worlds/                     世界観（純粋なデータ。エンジンは中身を知らない）
  index.js                     レジストリ。useWorld() で切り替え、購読側が追従する
  fantasy.js                   剣と魔法
  neon.js                      サイバーパンク（サイバーウェア込み）
js/core/                       ゲームロジック（DOM に触れない・Node でテストできる）
  rng.js                       シード付き乱数（同じ種なら同じ展開を再現）
  dice.js                      ダイス式の解析と判定
  rules.js                     d20 ルール（判定・攻撃・ダメージ・状態・休憩・成長）
  content.js                   有効な世界観への live view（let 束縛で追従する）
  character.js                 キャラクター生成と派生値
  combat.js                    ターン制戦闘と敵AI
  augment.js                   サイバーウェアと適合度
  netrun.js                    電脳侵入の状態機械
  scenario.js                  シナリオ形式・条件・効果・点検
  engine.js                    ソロプレイの進行（セーブ／ロード込み）
  store.js                     localStorage 保存
js/ui/                         画面（DOM のみ）
js/scenarios/                  収録シナリオ
tools/                         ローカルサーバー、配信ビルド、アイコン生成、ブラウザ検証
```

ゲームロジックは DOM も `Math.random` も直接触らず、乱数はシード付き `Rng` を経由します。
同じ種なら同じ展開を再現でき、Node のテストから素で動かせます。

世界観は純粋なデータで、エンジン側は「何が存在するか」を知りません。
`js/worlds/` に同じ形のオブジェクトを足して `index.js` に登録すれば、
第三の世界観（宇宙、和風、ホラー……）をルールごと追加できます。

## 開発

```bash
npm start          # ローカルサーバー
npm test           # ユニットテスト132件（ダイス・ルール・戦闘・シナリオ／エンジン・世界観）
npm run smoke      # 実ブラウザで3モードと2世界を通しで操作（25項目・要 npm install）
npm run build      # www/ に配信用ファイルを出力
npm run icons      # アイコンを再生成
```

`main` に push すると GitHub Pages へ自動デプロイされます（`.github/workflows/deploy-pages.yml`）。
