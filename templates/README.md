# シナリオの JSON テンプレート

工房の「JSONを読み込む」に投げると、そのまま編集・プレイできます。

| ファイル | 何のための形 |
| --- | --- |
| `annotated.json` | **全機能の見本。** 使える書き方が一通り入っていて、`_comment` に説明がある |
| `linear.json` | 一本道。判定と戦闘を一度ずつ |
| `hub.json` | 拠点から複数の調査先へ。手がかりが揃うと次へ |
| `clock.json` | 変数が上限に達すると場面が強制的に変わる |
| `route.json` | 複数の道のうち二区間を通って目的地へ |

`_` で始まるキーはエンジンが読み飛ばすので、メモとして残したまま遊べます。

骨組みだけ欲しいときは、コマンドからも作れます。

```bash
npm run new -- my-scenario --shape=hub --world=neon --title="題名"
```
